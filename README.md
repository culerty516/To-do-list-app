# To-do List App

This repository contains a simple web-based To-do list application. It lets you add tasks, mark them as complete, and remove them from the list.

## Setup

1. Clone the repository.
2. Open `index.html` in your web browser.

No additional dependencies or build steps are required.

## Usage

- Type a task in the input field and click **Add** (or press Enter) to add it to the list.
- Click on a task to toggle its completed state.
- Click **Delete** next to a task to remove it.
